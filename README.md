# masterplan

연도별·월별로 예산, KPI, 전략, 성과 리포트, 광고 소재를 관리하는 단일 페이지(`index.html`)입니다.
데이터는 브라우저 IndexedDB에만 저장돼요.

## Meta 대용량 셋팅

월 편집 창 → **Meta 대용량 셋팅** 탭에서 캠페인·광고세트·광고를 한 번에 만들 수 있어요.

### 1. 셋팅 시트 만들기
- **자동 생성**: 이번 달 KPI(인지도/트래픽/구매 최적화/회원가입) → 캠페인 목표, 월 예산 → 일 예산, 광고 소재 탭 이미지 → 광고로 변환해 초안을 만들어요. 광고세트는 연령 3구간·성별·분할 없음 중 하나로 나눠요.
- **CSV**: `템플릿 CSV 받기`로 받은 파일을 엑셀에서 채운 뒤 업로드해요. 한 행이 광고 1개이고, 캠페인명·광고세트명이 같은 행끼리 묶여요.

| 열 | 예시 | 비고 |
|---|---|---|
| 캠페인명 / 캠페인목표 | `202612_구매` / `OUTCOME_SALES` | 한글(판매·트래픽·인지도·참여·잠재고객)도 인식 |
| 광고세트명 / 일예산 | `25-34_여성` / `50000` | 광고계정 통화 기준 (KRW 계정은 원 단위) |
| 시작일 / 종료일 | `2026-12-01` | YYYY-MM-DD |
| 국가 / 최소연령 / 최대연령 / 성별 | `KR` / `25` / `34` / `female` | 성별: all·male·female(남·여) |
| 최적화목표 / 전환이벤트 | `OFFSITE_CONVERSIONS` / `PURCHASE` | 전환 최적화면 픽셀 ID 필수 |
| 광고명 / 소재명 / 이미지URL | | 소재명이 광고 소재 탭 이미지명과 같으면 그 이미지를 업로드 |
| 본문 / 제목 / 랜딩URL / CTA | | CTA: SHOP_NOW, LEARN_MORE, SIGN_UP 등 |

업로드하면 필수값·날짜·연령·국가 코드·픽셀·이미지 여부를 검증하고, 일 예산 합계와 월 예산 대비 집행 비율을 보여줘요.

### 2. 실행 (모두 PAUSED 상태로 생성)

**A. Meta Ads MCP (권장)**
1. 이 저장소의 `.mcp.json`에 Meta 공식 Ads MCP(`https://mcp.facebook.com/ads`)가 등록돼 있어요. Claude Code에서 이 폴더를 열고 `/mcp`로 `meta-ads` 서버에 Facebook 계정으로 로그인해요. claude.ai에서는 설정 → 커넥터에서 같은 URL을 커스텀 커넥터로 추가해요.
2. 페이지에서 `작업 지시서 복사`를 눌러 Claude에 붙여넣어요. Claude가 캠페인 N개 단위로 생성하고 name→ID 표를 보고해요.
3. 광고 소재 탭에만 있는 이미지는 지시서에 넣지 않아요(용량). 이미지URL을 쓰거나, 광고계정 미디어 라이브러리에 같은 이름으로 먼저 올려두세요.

> Meta 공식 Ads MCP는 2026년 4월 오픈 베타로 공개된 것으로 알려져 있어요(2차 출처 기준). 엔드포인트가 바뀌면 `.mcp.json`의 URL만 고치면 돼요.

**B. Marketing API 직접 실행**
- `ads_management` 권한이 있는 액세스 토큰을 넣고 실행해요. 토큰은 저장하지 않아요.
- 먼저 DRY-RUN(기본값)으로 호출 내용을 확인하세요.
- 호출 간격(기본 1.2초)을 두고, 레이트 리밋 오류(code 4·17·613·80004 등)는 30초→60초→120초 간격으로 재시도해요.
- 중간에 멈추면 생성된 ID가 기록돼서, 다시 실행할 때 이미 만든 항목은 건너뛰고 이어서 진행해요.
- API 기본 버전은 `v24.0`. v24부터 필수인 `is_adset_budget_sharing_enabled=false`(광고세트 예산 사용)를 보내요.
