# 퍼포먼스 마케팅 팀 공통 작업 기준

모든 팀원(서브에이전트)은 작업 시작 전에 이 문서를 읽고 따른다.

## 1. 공통 원칙
1. **실행 가능성 우선**: 이상적인 안보다 예산·인력·일정 제약 안에서 실행 가능한 안을 우선 제시한다. 모든 제안에 "누가 / 언제 / 어떻게"를 붙인다.
2. **최신성**: 플랫폼 정책, 광고 상품, 벤치마크는 작업 시점에 검색해서 확인한다. 트렌드를 언급할 때는 시점을 적는다 (예: "2026년 하반기 기준").
3. **출처 필수**: 수치·통계·사례에는 출처(매체명, 문서명, URL, 발행일)를 단다. 출처가 없는 값은 `[추정]` 또는 `[가정]` 태그를 붙이고 근거 논리를 한 줄 이상 적는다.
4. **과장 금지**: "무조건", "반드시 오른다" 같은 단정 표현은 쓰지 않는다. 예상 범위, 전제 조건, 리스크를 같이 적는다.
5. **앞 단계 산출물 존중**: 앞 단계 산출물과 다르게 판단하면 임의로 바꾸지 말고 `## 이견 및 제안` 섹션에 근거와 함께 남긴다.

## 2. 산출물 위치와 파일명
프로젝트마다 `outputs/<프로젝트명>/` 폴더를 쓴다.

| 순서 | 담당 | 파일 |
|---|---|---|
| 0 | 사용자/리드 | `00_brief.md` (템플릿: `team/templates/brief.md`) |
| 1 | 5번 리서처 | `01_factbook.md` |
| 2 | 1번 전략가 | `02_strategy.md` |
| 3 | 2번 미디어 플래너 | `03_media_mix.md`, `03_media_mix.csv` |
| 4 | 3번 소재 기획자 | `04_creative_brief.md` |
| 5 | 4번 소재 제작자 | `05_creatives/` (카피, 이미지 프롬프트, 영상 콘티, 배너 HTML 등) |
| 6 | 6번 검수자 | `06_qa_report.md` |

리서처는 다른 단계에서 추가 조사 요청이 오면 `01_factbook.md`에 `## 추가 조사 (요청자: OO)` 섹션으로 덧붙인다.

## 3. 표기 규칙
- 통화는 원(KRW)으로, VAT 포함 여부를 적는다 (기본: **VAT 별도**).
- 비율은 소수 둘째 자리까지 (CTR 1.25%). 금액은 천 단위 콤마.
- KPI 용어: 노출(Imp), 클릭(Click), CTR, CPC, CPM, CVR, CPA, ROAS(=매출/광고비×100%), CAC, LTV.
- 날짜는 `YYYY-MM-DD`. 기간은 시작·종료일을 모두 적는다.

## 4. 각 문서 맨 위에 넣을 헤더
```
- 프로젝트: <이름>
- 작성: <N번 팀원 / 역할>
- 작성일: YYYY-MM-DD
- 참조 문서: <앞 단계 파일 목록>
- 데이터 한계: <샘플, 기간, 추정치 비중 등>
```

## 5. 핸드오프 체크
각 문서 마지막에 `## 다음 담당자에게` 섹션을 두고, 다음 단계가 꼭 알아야 할 결정사항, 미확정 항목, 확인 요청을 적는다.
