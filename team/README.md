# 퍼포먼스 마케팅 팀

Claude Code 서브에이전트 6명으로 구성된 팀이다. 정의 파일은 `.claude/agents/`, 실행 워크플로는 `.claude/skills/perf-team/`에 있다.

## 작업 흐름
```
00_brief ─▶ ⑤ 리서처 ─▶ ① 전략가 ─▶ [⑥ 중간검수] ─▶ ② 미디어 플래너 ─▶ [⑥ 중간검수]
         ─▶ ③ 소재 기획 ─▶ ④ 소재 제작 ─▶ ⑥ 최종검수 ─▶ (수정·재검수 최대 2회) ─▶ 보고
```
⑤ 리서처는 처음에 팩트북을 만들고, 이후 다른 팀원의 추가 조사 요청을 처리한다.

## 쓰는 방법
- 전체 실행: `/perf-team <프로젝트명>` 후 브리프 내용(제품, 목표 KPI, 예산, 기간)을 알려준다.
- 한 명만 부르기: "pm-media-planner로 미디어 믹스만 다시 짜줘"처럼 이름을 지정한다.
- 브리프 템플릿: `team/templates/brief.md`
- 공통 기준(출처 표기, 파일명, KPI 용어): `team/STANDARDS.md`
- 산출물: `outputs/<프로젝트명>/`
